# Paceline

## Project Overview
Paceline is a premium running and lifestyle footwear brand website built as a responsive React + Vite storefront. The project recreates a premium editorial ecommerce aesthetic inspired by the provided Paceline design reference.

## Features
- Responsive home page and Our Story route
- Sticky navigation and mobile hamburger menu
- Search modal for product discovery
- Product filtering by category
- Add-to-cart interactions with localStorage persistence
- Newsletter signup validation with success feedback
- Accessible buttons, labels, and keyboard-friendly interactions

## Tech Stack
- React
- Vite
- JavaScript
- HTML/JSX
- CSS
- React Router

```bash
npm run build
```

## Deployment
This project can be deployed to Vercel or Netlify using the standard Vite build process.

### Vercel
1. Import the repository into Vercel.
2. Set the framework preset to Vite.
3. Deploy the app.

### Netlify
1. Connect the repository to Netlify.
2. Set the build command to `npm run build`.
3. Set the publish directory to `dist`.
